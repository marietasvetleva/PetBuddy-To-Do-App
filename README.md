
# Pet Buddy — Health & Habit Tracking App

A mobile application developed using Swift and SwiftUI to help young adults build and maintain healthier daily habits through gamification and an interactive virtual pet.

## Project Overview

Maintaining healthy routines can be challenging, especially when motivation decreases over time. Traditional habit-tracking applications often focus on recording progress without providing an engaging experience.

Pet Buddy addresses this challenge by combining habit management with a virtual pet system. Users can track activities related to exercise, hydration, sleep and mental wellbeing while caring for a digital pet whose wellbeing is influenced by their progress.

The goal is to make habit tracking more interactive, motivating and rewarding.

## Key Features

### Habit Management
- Create, view, edit and delete personal habits.
- Mark daily habits as completed.
- Track progress towards healthier routines.

### Interactive Virtual Pet
- Virtual pet displayed on the home screen.
- Pet wellbeing, emotions and energy levels respond to user activity.
- Encourages users to maintain consistent habits.

### Progress Tracking & Rewards
- Track completed tasks and daily progress.
- Monitor habit streaks.
- Earn rewards through habit completion.
- Receive visual feedback through gamification.

### Data Persistence
- Save and retrieve user habits.
- Store progress, streaks and rewards.
- Maintain application data between sessions.

## Design & Development Process

The project followed an iterative development approach, covering research, planning, design, implementation and testing.

### 1. Research & Requirements
- Investigated challenges young adults face when maintaining healthy habits.
- Researched existing health and habit-tracking applications.
- Defined the target users and project objectives.
- Prioritised functionality using the MoSCoW method.

### 2. UI/UX Design
- Created paper wireframes to explore layouts and interactions.
- Developed an interactive prototype using Figma.
- Gathered feedback on the proposed design.
- Conducted user testing to identify usability improvements.

### 3. Application Development
- Implemented the core habit management functionality.
- Developed the virtual pet system with changing wellbeing and energy levels.
- Added progress tracking, streaks and reward interactions.
- Implemented data persistence to retain user information.

### 4. Testing & Evaluation
- Conducted user testing to evaluate the application experience.
- Reviewed feedback to identify usability issues.
- Documented limitations and opportunities for future improvements.
- Created a video demonstration of the application.

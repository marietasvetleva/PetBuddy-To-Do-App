# Case 2 - Health App


## Project Description
This project is a mobile application designed to help young adults improve their health habits. 
The app motivates users to complete daily habits such as exercising, sleeping well and reducing stress by using a virtual pet system. 
By completing habits, users take care of their digital pet and maintain its wellbeing.

---

## Features
- Habit tracking
- Virtual pet system
- Daily tasks and progress tracking
- Motivational system for healthy behaviour

---

## Technologies Used
- Swift (programming language)
- SwiftUI (framework)
- Jira (project management)
- Figma (design & prototyping)
- GitLab (version control)
